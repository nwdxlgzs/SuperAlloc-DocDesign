# SuperAlloc

面向语言运行时、游戏引擎和数据库的多实例用户态内存分配器设计。

每个实例独占一段连续虚拟地址范围，在同一区域内提供至少 16B 对齐的对象分配和按系统页对齐的页映射；实例内部完成元数据自举，支持多线程、映射存储和受限实时分配。

**项目当前处于设计文档阶段，没有可用的分配器实现，也没有性能测量结果。** “低延迟、高吞吐、领先适用基线”是需要验证的目标，不是已有结论。本阶段不创建源代码、构建系统或接口头文件。

## 核心约束

- C++20 内部实现、稳定 C ABI；显式多实例，不替换系统 malloc/mmap/new/delete。
- 一个实例、一段连续地址保留范围、统一区间账本；内部可以存在多个内核 VMA/view。
- 64 位容量设计范围 16MiB～4TiB；32 位 Android 使用独立地址上限，所有平台都需要实际保留成功。
- 所有可增长管理结构计入所属实例；不隐式使用外部堆或额外地址区域。
- 普通模式、持久模式和受限实时模式有独立成本与契约，不能把一种模式的性能或保证套用到另一种。
- 普通对象释放不因管理内存不足失败；实时合法跨线程释放不因队列容量不足失败。
- 用户数据事务、跨进程分配器和任意 ABI 的持久对象迁移不属于首版。
