## 术语

| 术语 | 本项目含义 |
| --- | --- |
| arena / 实例 | 独占连续虚拟地址范围及其全部分配器状态 |
| reservation | 地址所有权；不等于全部物理内存或磁盘已经分配 |
| extent | 以系统页为基础的连续区间及其所有权、backing 状态 |
| broker | 本实例页区间所有权管理入口 |
| backing | 地址所关联的匿名内存、主文件或外部文件 |
| view / VMA | OS 映射记录；不能与一个 arena 等同 |
| heap / owner | 管理一组 slab 的逻辑分配上下文及当前独占操作者 |
| slab / span | 为一类对象取得的页区间；具体字段以技术文档为准 |
| thread context | 与一个 arena incarnation 和一个线程绑定的运行时上下文 |
| incarnation | 实例或上下文的某一次生命周期身份，不是对任意悬垂指针的安全保证 |
| commit / backing charge | 后端资源状态；Windows commit charge、POSIX 可访问页和 resident 不等价 |
| quiescent | 调用方已经阻止新进入，并确认所有相关操作/访问退出；仅取锁不构成 quiescence |
| Pending | 已由 broker 独占、尚未完成后端操作的范围 |
| Quarantined | 后端状态无法可靠恢复，禁止重新分配的范围 |
| durable | 在声明的本地文件系统/flush 契约下完成持久提交，不推断不受控硬件保证 |
| RT | 分配器工作量受限的预备模式，不是通用 OS 的硬实时调度保证 |

容量使用二进制单位：KiB、MiB、GiB、TiB。对象大小、页数量、地址长度和文件长度是不同量，换算必须检查溢出。

## 状态标签

- **已确定**：用户确认或与之兼容的设计基线；变更需要同步 API、决策和验证文档。
- **设计基线**：用于指导首个实现的参数或结构，尚未有运行证据。
- **待验证**：已给出实验和退出条件的系统/性能假设，不作为已实现能力宣传。
- **后续**：不属于首版保证，也不阻塞当前文档完成。

文档里出现函数名仅表达接口契约；当前没有可编译头文件。二进制 ABI、结构大小和磁盘字节布局的冻结是后续有明确门槛的任务。
